Joining the Zavod server

Minecraft 1.7.10 · hardcore industrial modpack · whitelist only

The server is not on the open internet. It sits in a small private network, and only devices I invite can reach it — no griefers scanning ports, no strangers. To join, you install the open-source Tailscale client and connect it to that network with a one-time key I send you. Below is exactly what that gives me and what it doesn't.

What I can and can't do

I can see

  • the name of your device in the network — it's set to zavod-<your nick>, not your computer's name;
  • its OS and client version;
  • your public IP address and when you're online — the control server needs them to connect you;
  • normal Minecraft server logs: your nick, join/leave times, chat.

I can't

  • connect to your computer: your client runs with --shields-up, which refuses every incoming connection, whatever the server says;
  • see or redirect your internet traffic: no exit node, no routes, your DNS is left alone (--exit-node=, --accept-routes=false, --accept-dns=false);
  • install or run anything on your PC (--ssh=false, and the client has no such feature for the network owner);
  • let players reach each other — the rules below allow one thing only.

All of these are settings on your side. You can check them yourself at any time (step 3 below), and nothing I change on the server can switch them back.

The network rules, verbatim

This is the whole access policy of the network. Members can open a connection to one port of one machine — the Minecraft server. Nothing else.

{
  "hosts": {"zavod": "<server address>/32"},
  "acls": [
    {"action": "accept", "src": ["*"], "dst": ["zavod:25565"]},
    {"action": "accept", "src": ["<admin>@"], "dst": ["zavod:8443", "zavod:53"]}
  ]
}

The second line is for me only: the admin panel of the server (invites, whitelist, backups) and a DNS resolver on the server for my own PC. Both live on the server, not on anyone's PC, and no other account can reach them.

Devices also can't add themselves or advertise routes: joining needs a single-use key from me (it expires in 48 hours), and route or exit-node offers from any device are never approved.

How to join

  1. Install Tailscale: tailscale.com/download (Windows, macOS, Linux). No Tailscale account needed.
  2. Run the one line I send you. Windows — Command Prompt; macOS/Linux — terminal, with sudo. It looks like this: 
    tailscale up --login-server https://<server> --authkey <one-time key> --hostname zavod-<nick> --shields-up --accept-dns=false --accept-routes=false --exit-node= --ssh=false
  3. Check it took: run tailscale debug prefs and look for these four values.
    "ShieldsUp": truenothing can connect to your device
    "CorpDNS": falseyour DNS is untouched
    "RouteAll": falseno routes from the network
    "ExitNodeID": ""your traffic goes out as usual
  4. Install the modpack (Prism Launcher zip or the updater — links in the pack thread), then Minecraft → Multiplayer → Direct Connection → the address I send.

Leaving

tailscale logout disconnects you from the network for good; uninstalling Tailscale does the same. If you already use Tailscale for something else, the join command switches your client to this network — switch back with tailscale up --login-server <yours>, or log out first.

The server side

The server runs Headscale (an open-source control server for Tailscale clients) and Minecraft on one rented machine. Minecraft listens only on its private-network address — the port isn't open to the internet at all. The game runs as an unprivileged user inside a locked-down systemd sandbox; the server software is read-only to it. I administer the machine over SSH with a key, no passwords. World backups run daily.
