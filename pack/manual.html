No scripts, no updater: every file below links to where it actually comes from (CurseForge, Modrinth, or this site for the modpack's own files). The updater installs exactly this list — use whichever you trust more.

Steps / Шаги

  1. Minecraft 1.7.10 with Forge 10.13.4.1614 (any launcher), Java 8. Майнкрафт 1.7.10 + Forge 10.13.4.1614 в любом лаунчере, Java 8.
  2. In the game folder, move the old mods/ and scripts/ folders somewhere else (backup). В папке игры убери старые mods/ и scripts/ (в резервную копию).
  3. Download all 34 mods below into the folder shown in the first column (mods/ or mods/1.7.10/). Don't rename them. Скачай все моды из таблицы в папку из первой колонки. Имена не меняй.
  4. Download Zavod-files-1.57.49.zip (configs, scripts and content packs, 159 files) and unpack it into the game folder, replacing files. Скачай архив и распакуй в папку игры с заменой файлов.
  5. When the version at the top of this page changes, repeat steps 2–4. Сменилась версия наверху страницы — повтори шаги 2–4.
