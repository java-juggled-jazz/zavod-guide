ZAVOD

Hardcore industrial realism · Minecraft 1.7.10 · version 1.57.6

You start with a field, a hammer and black powder. You end with turbines, refineries, rails, a reactor and a rocket on the pad. No magic, no shortcuts: every machine is heavy, built from parts you made, and has its own niche. A steam turbine wants a river, a gas turbine wants a gas field, a diesel wants fuel hauled in. The world is hostile — difficulty is locked to Hard, and fortified outposts with garrisons sit between you and the good loot.

1 · Farmfields, black powder, bloomery iron
2 · Steamcoke, steel, shafts, machine tools, rail
3 · Electricitydynamos, electrolysis, first engines
4 · Oilcracking, gas turbines, synthetics
5 · Atom & spacegraphite, heavy water, satellites
Preview build. The pack is still changing — mods get cut, recipes and blocks get reworked. Worlds may break between versions: back up your saves folder before launching if a world matters to you. A small whitelist server comes later; singleplayer progress doesn't carry over.

Download

Forge 1.7.10-10.13.4.1614 · Java 8 · give it about 4 GB of RAM.

Prism Launcher easiest

Updates itself every launch. Best choice on Apple Silicon Macs.
  1. Install Prism Launcher.
  2. Add Instance → Import → paste the link below → OK.
  3. Launch. Prism fetches Forge, Java and the mods.
Zavod-Prism.zip

Any launcher + updater

For whatever launcher you already use.
  1. Make a Forge 1.7.10-10.13.4.1614 profile.
  2. Unzip into the game folder (next to mods/).
  3. Before playing run zavod-update.bat (Windows) or sh zavod-update.sh.
Zavod-updater.zip

By hand

No scripts at all. Every mod links to where it comes from, with checksums.
  1. Download each mod from the list.
  2. Unzip the config archive into the game folder.
  3. Repeat when the version changes.
Manual install

The updater is a ~30-line script you can read, plus the open-source packwiz installer. It downloads exactly the list on the manual page, verifies every checksum, and only ever removes files it installed itself. On first run it moves your old mods/ and scripts/ into zavod-backup/.

What's inside

A custom core mod, Zavod, with its own machines and multiblocks — steam, gas and diesel turbines, coke batteries, a seismic station, an engineering bureau, a launch pad — and patches that pull the mods below into one tech tree. Built on:

  • IndustrialCraft 2 (experimental)
  • BuildCraft + Logistics Pipes
  • Railcraft
  • Forestry
  • Flan's Mod
  • Pam's HarvestCraft
  • Climate Control (Earth-like climate bands)
  • Recurrent Complex (forts, outposts)
  • Nuclear Control
  • Storage Drawers, Iron Chests, BiblioCraft
  • NEI, Waila, Xaero's Minimap
  • MineTweaker

Full list with versions: manual install page. Machine guide: the Engineer's handbook — also in game as a book.
