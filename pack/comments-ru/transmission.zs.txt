// ====================================================================================
// ТРАНСМИССИЯ ПАРОВОЙ ЭПОХИ (zavod.jar): паровая машина крутит вал, вал через шкивы крутит станки.
// Вал прямой (как в цеху под потолком), поворот и развилка - редуктором. Станок ставится рядом со шкивом сбоку.
// Машина тратит пар только под нагрузкой: станки стоят - пар цел. Перегруз - обороты падают у всех.
// Правый клик пустой рукой по валу - что на линии: машины, л.с., станки, звенья.
// ====================================================================================

Вал: железный вал на двух бабиттовых втулках (подшипники скольжения) -> 4 звена.
Шкив: деревянный шкив на валу + кожаный ремень к станку.
Редуктор: бронзовые шестерни в железном корпусе.
Паровая машина низкого давления (бронза): цилиндр с поршнем, паровая коробка (стенка бака Railcraft), вал, маховик.
Паровая машина высокого давления (сталь): стальной вал и шестерни, станина из стальных блоков; в 5 раз мощнее.

ПРОВОЛОКА: кусачками из пластины не делается - только волочением через фильеры.
Вручную - волочильная доска (стальная пластина с рядом отверстий), 64 протяжки; мало и дорого.
На валу - волочильный стан: больше проволоки со слитка и пачкой по 4 слитка.
(Металлоформовщик IC2 - электрический путь, остаётся.)
Убраны рецепты IC2: медный, оловянный, золотой провод из пластины кусачками.

ЭКСКАВАТОР (карьер на валу): копает ВСЁ позади себя слоями до дна, через люки - в сундуки и вагонетки.
Режим засыпки - порода обратно в карьер, сверху земля. Люк: всё / полезное / отвал (Shift + пустая рука).
Паровой экскаватор: ковши (ведро), бронзовые шестерни и железный вал, ковшовая цепь (железные прутья).
Тяжёлый экскаватор: из парового + сталь, стальной вал, станина из стальных блоков.
Люк выгрузки: воронка между двух железных пластин.

РУДНАЯ ТОЛЧЕЯ (на валу): песты на кулачковом валу толкут пачку 8 шт.
Руда -> пыль 1 : 1.5; булыжник -> гравий; гравий -> песок + глина (1 на 4) + кремень (1 на 8).
Рецепт: кулачковый вал (железный вал, железные пластины), песты (поршни, бронзовая шестерня), ступа (котёл, стальные пластины).

Секция стрелы экскаватора: решётчатая ферма (железные прутья + пластина); столбиком на экскаватор, каждая - ещё квадрат карьера назад.
ПАРОВОЙ НАСОС (поршневой, на валу): ставится прямо над водой, отдаёт воду в соседние котлы, баки, трубы.
Источник с двумя соседними источниками (пруд, река, море) не убывает; лужу выкачивает.
Рецепт: медная пластина (напорный патрубок), поршень, железный вал, бронзовая шестерня, ведро, железные пластины.
