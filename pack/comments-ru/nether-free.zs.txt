// ПОЧЕМУ: Нижний мир в сборке - не источник ресурсов. Всё, что делается в Верхнем мире,
// делается из материалов Верхнего мира. Без замены остались только поздние и "магические" вещи

// Светопыль при этом добываема: IC2 - редстоун + золотая пыль (скрытый рецепт, в NEI не виден).
// Рецепты, которые MT не адресует (путь посадки, паяльная станция LP, фонари BiblioCraft,
// сигнальная лампа RC, сборочный стол BC), меняет zavod.jar (NetherSwap) - форма рецепта родная, заменён один ингредиент.

ВАНИЛЬ
- Лампа редстоуна: стеклянная колба, медная нить накала (кабель IC2), 4 редстоуна. БЫЛО: блок светокамня.
- Компаратор: медная пластина-контакт (реле сравнения). БЫЛО: адский кварц.
- Датчик дневного света: кремниевый фотоэлемент (3 кремния). БЫЛО: адский кварц.

IC2
- EU-метр: стекло шкалы. БЫЛО: светопыль.
- Пульт подрыва: редстоун-цепь вместо светопыли. Второй (без светопыли) рецепт возвращён как был.

RAILCRAFT
- Детекторы: у каждого свой материал корпуса. Поезд - железные пластины (сцепка), локомотив - бронзовые
  (паровая арматура), маршрут - медные (контакты билета). БЫЛО: адский кирпич / кирпич ифрита / кварц.
- Скоростной рельс: цементация коксом (закалка головки рельса), прокатный стан. БЫЛО: порошок ифрита.
- Путеперекладчик: поршни-манипуляторы вместо стержней ифрита.

BUILDCRAFT
- Кварцевая труба = труба из кварцевого (простого) стекла: 3 стекла в ряд -> 8. БЫЛО: блоки адского кварца.
- Кварцевый чипсет (сборочный стол, после чертежа лазера): кремний вместо адского кварца - в zavod.jar,
  MT этот стол в BC 7 не поддерживает. Без чертежа кварцевого чипсета по-прежнему нет.

FORESTRY / THERMAL EXPANSION
- Стабилизатор улья: свинцовый экран от мутаций (6 пластин). БЫЛО: адский кварц.
- Экскурсионная плита TE: закалённое стекло вместо блоков кварца.
