Селитра/соль/ацетат + серная → азотная/соляная/уксусная; киноварь → ртуть (без кислоты). Огонь.

На огне. Соль кислоты + 500 mB серной → кислота: селитра → 350 mB азотной, соль → 500 mB соляной, ацетат кальция → 500 mB уксусной. Киноварь — без кислоты, обжиг → 125 mB ртути (на гремучую ртуть для капсюлей). Киноварь падает при добыче красной руды (кирка 25 %, удача больше, экскаватор тоже).

Кто кормит

  • dustSaltpeter ← Химический реактор, Реактор высокого давления
  • Ацетат кальция ← Химический реактор, Реактор высокого давления
  • Киноварь ← Рудная толчея
  • Соль ← Выпарной аппарат, Солеварня
  • Серная кислота ← Контактный аппарат, Свинцовая камера

Кого кормит

  • Соляная кислота → Смеситель
  • Азотная кислота → Химический реактор, Реактор высокого давления, Смеситель
Как устроено (из кода)

Кирпичная реторта на огне (метод Глаубера, XVII в.): соль кислоты + серная кислота при нагреве, летучая кислота отгоняется в приёмник. селитра + 500 mB серной -> 350 mB азотной (азотная разлагается при отгонке - потери) соль + 500 mB серной -> 500 mB соляной ацетат кальция + 500 mB серной -> 500 mB уксусной (1.56.28, лесохимия; гипс остаётся в реторте) киноварь без кислоты -> 125 mB ртути (обжиг HgS -> Hg + SO2, пары ртути конденсируются; B1 чат 3, было - тигель TE) Партия 20 с огня (1 уголь = 4 партии). Зольник (Ash): дрова - древесная зола, уголь/кокс - угольная; полон - огонь гаснет. Слоты: 0 сырьё, 1 топливо, 2 зола. Баки: 0 серная (вход), 1 продукт.
